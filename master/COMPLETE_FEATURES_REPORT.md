## 📊 数据流程

### 读取流程
```
用户点击菜单
  → 调用 loadXxx()
    → api.xxx.getList()
      → 后端API
        → MySQL数据库
          → 返回JSON数据
            → generateXxxTable()
              → 渲染HTML
```

### 创建流程
```
用户点击"添加"
  → 显示模态框
    → 填写表单
      → 点击"提交"
        → 验证必填字段
          → api.xxx.create(data)
            → 后端保存
              → 返回结果
                → 关闭模态框
                  → 重新加载列表
                    → 更新统计
```

## 🔄 页面刷新机制

由于服务器静态文件缓存问题，如果修改后页面未更新：

### 方法1：强制刷新浏览器
```
Chrome/Edge: Ctrl + Shift + R
Firefox: Ctrl + F5
Safari: Cmd + Shift + R
```

### 方法2：清除浏览器缓存
```
1. 打开开发者工具（F12）
2. 右键点击刷新按钮
3. 选择"清空缓存并硬性重新加载"
```

### 方法3：重启服务器
```bash
pkill -9 -f boost_server
cd /home/parallels/chenglei_work/2025/BoostPro1/master/build
./boost_server &
```
